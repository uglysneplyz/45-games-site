PLAYROOM — 45 игр

1. Распакуй весь архив в одну папку.
2. Открой index.html в современном браузере.

Установка и сервер не нужны. Рекорды и избранное сохраняются в браузере.
Для загрузки шрифтов нужен интернет; без него используются системные шрифты.

icons.js — иконки всех 45 игр, иконки интерфейса, бегущая лента, эффекты.
